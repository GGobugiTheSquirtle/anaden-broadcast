## 번역 오류 (Translation Errors)

- [bt_001] 파티원 이름 `リィア` → 번역: "리아" | 실제 화면 하단에 `リィア`로 표기. 정확한 음역은 **리이아** (리아로 축약 오기) → `리이아`로 수정
- [bt_001] `シーラス` → 번역: "시라스" | 스크린샷 상 적 캐릭터명 `シーラス`는 **사이러스**(Cyrus) 또는 **시라스**가 아닌 **시라스**에 해당하나, bt_008 이후 동일 캐릭터가 `サイラス`로 표기됨 → 동일 캐릭터 여부 검토 필요. bt_001의 `シーラス`와 bt_008 이후 `サイラス`가 서로 다른 캐릭터일 수 있음 (적 vs 아군 구분 혼동 주의). bt_001 화면에서 `シーラス`는 **적 측** 이름표로 표시됨 — 번역에서 아군 캐릭터처럼 기술한 것은 오류 → 문맥 수정 필요
- [bt_004] 적 이름 `飯飽の化身` → 번역: "이안의 화신" | `飯飽`는 고유 명사로 "이안"이 아니라 **"반포(飯飽)"** 또는 원어 표기 유지 필요. 이 한자는 일반 훈독으로 읽으면 "메시아키"지만 고유명이므로 함부로 한국어 음역 불가 → `飯飽の化身 (원어 표기 유지)` 또는 스토리 맥락 확인 필요
- [bt_005] 스킬명 `京都斬り` → 번역: "교토 베기" | `京都斬り`는 실제로는 **`京都` (교토)**가 아닌 게임 내 고유 스킬명일 가능성 높음. 스크린샷 bt_005 확인 시 해당 슬롯에 보이는 글자가 `京都斬り`보다 다른 한자일 수 있음 — 해상도 한계로 단정 불가하나 지명을 스킬명으로 번역한 것은 재확인 필요
- [bt_006] 하단 설명문 번역 `체인 포인트가 쌓이면 자동으로 발동` | 스크린샷 bt_006 실제 텍스트: `チェインポイントが貯まると、自動的に発動` → 번역은 정확함. 단, 원문 `貯まる`(저금처럼 모이다)를 `쌓이면`으로 번역한 것은 자연스러우나, 공식 한국어화 예정이라면 **"채워지면"** 또는 **"모이면"**이 더 자주 쓰이는 게임 용어

## 캐릭터 이름 불일치 (Character Name Inconsistency)

- [bt_001 vs bt_025~028] `リィア`(bt_001) vs `リィガ`(bt_025, bt_026, bt_028) — 분석 내에서 동일 파티 슬롯의 캐릭터가 두 가지 표기로 나뉨. 번역도 각각 "리아" / "리가"로 다르게 처리됨. 실제 두 이름이 다른 캐릭터인지, 아니면 동일 캐릭터의 오독인지 확인 필요. 화면 해상도상 `リィア`와 `リィガ`는 구별 가능 → **별개 캐릭터이면 일관된 번역 유지**, 동일 캐릭터이면 하나로 통일 필요
- [bt_011 vs bt_016] `ジュエミ`(bt_011, bt_016 등) — 스크린샷 bt_011 하단에 `ジュエミ`로 명확히 보임. 번역은 "주에미"로 표기됨. bt_028에서 같은 슬롯이 `ジュエミ`로 기재됐지만 번역이 "쥬에미"로 표기 → **"주에미"/"쥬에미" 혼용** (bt_011: 주에미, bt_028: 쥬에미). 통일: `쥬에미` 또는 `주에미` 한 가지로
- [bt_011 vs bt_001] `エィミ`(bt_001 번역: "에이미") vs `ジュエミ`(bt_011 번역: "주에미") — 화면상으로는 bt_001의 세 번째 캐릭터 이름이 `エィミ`인지 `ジュエミ`인지 요검토. bt_011 스크린샷에서 세 번째 파티원이 `ジュエミ`로 확인됨 → bt_001에서 동일 캐릭터를 `エィミ → 에이미`로 번역한 것은 오독 가능성 있음
- [bt_025 vs 캐릭터 표] 요약 표에서 `エィミ/ジュエミ`를 같은 캐릭터로 묶어 표기 — 이는 불확실한 가정을 사실처럼 기재한 것. 별개 캐릭터일 수 있으므로 `?`로 표시하거나 별도 항목으로 분리할 것

## 어색한 표현 (Awkward Phrasing)

- [bt_001] 우측 메뉴 속성 번역: `〈斬〉攻撃 CP` → "베기 공격 CP", `〈叩〉攻撃 CP` → "치기 공격 CP", `〈打〉攻撃 CP` → "때리기 공격 CP" | `叩`와 `打`를 각각 "치기"/"때리기"로 번역했으나 게임 내 속성명이 서로 다른 카테고리인지 확인 필요. 일반적으로 `〈打〉`는 **"타격"**으로, `〈叩〉`는 **"강타"** 또는 **"두드리기"**로 구분되는 경우가 많음. "때리기"는 너무 구어체
- [bt_001] `〈心〉攻撃 CP` → "마음 공격 CP" | `心`을 "마음"으로 직역했으나 게임 속성명으로서 어색함. 어나더에덴 시리즈 원작 기준으로 `心`은 **"심"** 또는 **"정신"** 속성에 해당할 수 있음 → 게임 용어집과 대조 필요
- [bt_003] 스킬명 `植叡の刀` → 번역: "식영의 칼" | `植叡`는 고유 한자 조합으로 "식영"이 맞는 음독이나, 의미상 번역("식물의 지혜의 칼" 등)인지 음독 유지인지 방침이 없음. 일본 RPG 고유 스킬명은 음독 유지가 원칙 — **`쇼쿠에이노 카타나` 또는 원어 병기** 권장
- [bt_006] `整合回復率` → 번역에서 누락 (korean_translation에 기재 없음) → 번역 추가 필요. "정합 회복률"로 직역하거나 게임 용어로 확인 필요
- [bt_020] 설명문 `アナザーパーティにチェンジ！` → 번역: "다른 파티로 교체 가능!" | 원문의 `アナザーパーティ`는 **"어나더 파티"**라는 게임 내 고유 용어로 보임. "다른 파티"로 의역하면 시스템 명칭의 뉘앙스가 소실 → `어나더 파티로 체인지!`가 적절
- [bt_021] 파티원 스킬 조건 `纏わりがを与えた時` → 번역: "얽힘 부여 시" | 원문에 `が`가 중복 삽입된 오타(`纏わりが`+`を`)가 있음. 원본 일본어 텍스트에 오독/오기가 있으므로 스크린샷 재확인 필요
- [bt_033] 어빌리티 설명 `いきなりブレイク（火）` → 번역: "즉시 브레이크 (불꽃)" | `いきなり`는 "갑자기/즉시"지만 게임 시스템 명칭으로는 **"선제 브레이크 (불꽃)"**이 더 자연스러울 수 있음. 어나더에덴 원작 용어 대조 권장

## 게임 용어 불일치 (Game Term Inconsistency)

- [bt_002 vs bt_007] `Chain!` 표시 번역: bt_002에서 "체인 발동"으로 번역, bt_007에서는 "체인 스킬"로 혼용 — 섹션 타이틀 `チェインスキル`(체인 스킬)과 배틀 내 `Chain!` 표시(체인)는 서로 다른 개념. 배틀 내 `Chain!`은 **"체인!"** 그대로, 섹션 타이틀은 **"체인 스킬"**로 구분 유지 필요
- [bt_006] `チェインポイント` → 번역: "체인 포인트" — 올바름. 단 축약 시 `CP`와 혼동 가능. `CP`는 `チェインポイント`의 약자임을 명시해야 함 (분석 내에서 CP를 콤보 게이지와 혼용하는 표현 없는지 점검 필요)
- [bt_033] `アビリティ習得` 섹션 타이틀 → 번역: "어빌리티 습득" — 올바름. 스크린샷 bt_033에서 `アビリティ習得`으로 확인됨 (일치)
- [bt_025] 섹션 타이틀 `アナザーフォース` → 번역: "어나더 포스" — 올바름. 스크린샷 bt_025에서 확인됨 (일치)
- [전체] `スキル` → "스킬", `チェイン` → "체인", `アビリティ` → "어빌리티", `コンボ` → "콤보", `クリティカル` → "크리티컬" — 전반적으로 일관 적용됨. 이상 없음
- [bt_020] `チェンジスキル` → 번역: "체인지 스킬" | 단, bt_006 섹션의 `チェインスキル`(체인 스킬)과 발음이 유사하여 독자 혼동 가능. 번역 내 구분 설명 추가 권장 (`체인지 스킬 ≠ 체인 스킬` 주석)
