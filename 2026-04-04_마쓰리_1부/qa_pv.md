## 발견된 이슈

### 번역 오류

- [pv_001] `フィーネ` / `アルド`를 `（フィーネ）` / `（アルド）` 괄호 발화자 표기로 기술했으나, 실제로는 해당 텍스트 줄 위에 붙은 **루비(읽기 주석)** 임. 발화자 레이블이 아니라 주석임을 구분해야 함 → `ルビ: フィーネ (읽기)` / `ルビ: アルド (읽기)` 형태로 구분 표기 권장

- [pv_006] 우측 CP 패널의 `属＞攻撃 CP` → 번역 `속성 공격 CP`. 화면 원문은 실제로 `弱点攻撃 CP` 계열 항목이며 `属` 판독이 의심스러움. `属` 단독으로 이 게임 CP 패널에 쓰이지 않음 → 원문 재확인 필요, 잠정 번역은 `약점 공격 CP`로 교체

- [pv_020] `人という方が　危なくて　寂しいの。` → 분석의 번역 `인간이라는 쪽이　위험하고　외롭다니까.`
  - `という方` = "라고 하는 쪽/존재" → `쪽이`보다 `인간이라는 존재가` 또는 `인간이란 게` 가 더 자연스러움
  - `寂しいの` 는 1인칭 독백 어조(`~の`) → `외롭다니까`보다 `외롭거든` 또는 `외로운 거야`가 어조에 맞음
  - → 권장: `「인간이란 게　위험하고　외로운 거야. ……뭐, 너한테 말해봤자　이해 못 할 것 같지만.」`

### 어색한 표현

- [pv_006] 적 이름 `槿薮のソル` → `무궁화 숲의 솔`. `薮(やぶ)` = 덤불·수풀(thicket), `숲(forest)`과 다름 → `무궁화 덤불의 솔` 또는 `무궁화 수풀의 솔`로 교체

- [pv_011] 스킬명 `クウトロドライブ` → `쿠우트로드라이브`. `クウトロ`는 이탈리아어 `quattro`(4) 유래 표기로 추정. 표준 외래어 표기 기준이면 `콰트로드라이브` → 최소한 `쿠아트로드라이브` 권장. `쿠우트로`는 비표준

- [pv_015] 벨트란 CV: 화면 원문 `小山 力也` → 분석 `코야마 리키야`. 외래어 표기법상 `고야마 리키야`가 맞음 (`小山` = こやま = Koyama, 어두 k는 `고`로 표기). → `고야마 리키야`로 교체

### 누락 텍스트

- [pv_006] 하단 4번째 슬롯 스킬명이 잘린 채 `エルノの` 로만 기재. 화면에서 실제로는 `エルノの祈り` 등 후속 텍스트가 있을 가능성이 높으나 캡처 시 잘림. `(잘림 — 전체 스킬명 미확인)` 명시 필요

- [pv_017] 우측 대형 텍스트로 `セテ` (캐릭터명)가 명확히 보임. 분석에서 `セテ 텍스트 보임 (캐릭터명 추정)` 으로 불확실 처리했으나, 프레임에서 충분히 판독 가능 → `세테` 로 확정 표기 권장. 발화자 `ティー` 도 화면 좌하단에 명확히 보임

- [pv_019] CV `神谷 佳正` 가 프레임에서 육안으로 판독 가능함에도 `(추정)` 처리. `가미야 요시마사` 로 확정 표기 권장 (`神谷` = かみや = Kamiya → `가미야`)

### 캐릭터명 일관성

- [pv_005, 006, 007, 008, 009, 011, 028] `リィカ` → 분석 전체에서 `리이카` 로 일관되게 표기됨. **일관성 유지 — 이슈 없음**

- [pv_009] 적 이름 `シーラス` → `시라스`. 단 인명 `シラス(Silas)`와 구별하기 위해 장음 처리 확인 필요. `シーラス` (장음 포함)이므로 `시라스`보다 `시라아스` 또는 `시라스`(관례 허용) — 게임 내 공식 표기가 있다면 우선 적용

- [pv_016] `ミュルス` → `미울스`. 외래어 표기 원칙상 `ミュ` = `뮤` → `뮬스` 또는 `뮤르스`가 더 가깝고 자연스러움. `미울스`는 이례적 표기 → 공식 표기 확인 후 교체 고려

### 게임 용어

- [pv_005] 우측 배너 `Chain Skill` → 번역에서 `Chain Skill`(영어 원문) 그대로 표기. 게임 내 공식 용어이므로 원문 유지 적절. **이슈 없음**

- [pv_006] 우측 배너 `CPを溜め、コンボを繋げ` → `CP를 모아, 콤보를 이어라`. 자연스럽고 게임 용어와 일치. **이슈 없음**

- [pv_007] `アナザーフォース` → `어나더 포스`. 게임 내 시스템 명칭과 일치. **이슈 없음**

- [pv_031] `STUDIO PRISMA`를 `제작 협력`으로 번역. 화면 크레딧 상 명확한 역할 구분이 없으며, STUDIO PRISMA는 시나리오/스토리 담당 스튜디오로 알려져 있어 `제작 협력`이 역할을 과소평가할 수 있음 → `스튜디오 프리즈마` (역할 표기 보류 또는 `시나리오 제작`) 권장
